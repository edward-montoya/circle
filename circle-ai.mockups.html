Second gate · same command

> /circle:brief

Shell command failed for pattern
"circle gate check --skill circle:brief"
[stderr] preflight not passed: knowledge
7/9 paths resolve. run circle preflight

A failed injected command aborts the whole skill invocation. Claude never receives the skill body — so a skill cannot be talked into skipping preflight.

The three mechanisms

denyPreToolUse on Edit/Write — the write block
abortInjected command in every skill body — the preflight gate
armSkill frontmatter hooks — /circle:start installs the block for the session

Ships in the plugin. Hooks in project settings need a workspace-trust dialog first; plugin hooks run the moment the plugin is enabled. That difference is the whole replication story.

task-118 acme/platform 3 files · 2 services

Rate-limit the public search endpoint

Search is the only unauthenticated write-path to Redis. One client can currently exhaust the connection pool for everyone. This adds a fixed-window limiter in front of it.

Goal · what "done" means

  • Verified by command — 100 requests in 60s from one IP returns 429 after the 60th. pnpm vitest run mw/rate-limit
  • Verified by command — authenticated traffic is unaffected. pnpm playwright test search
  • Verified by command — Redis pool utilisation stays under 60% at 500 rps. make loadtest:search
  • Human judgement — the 429 body is actionable for API consumers.

3 of 4 machine-checkable · the fourth is marked, not hidden.

Risks & unknowns

  • Fixed window allows a 2× burst at the boundary. Accepted for v1 — sliding window is a follow-up, recorded as an addendum.
  • No shared clock across api replicas. Redis is the counter, so this is contained — but it makes Redis a hard dependency of the request path.
  • Unresolved — no ADR covers limiter policy. docs/adr/ is registered but empty.

Definitions consulted

docs/architecture/services.md · docs/api/search.md · .circle/artifacts/prd/search-hardening.md — traceability: what the agent actually read, from the knowledge registry.

Three states you asked for implicitly

RewrittenAmended, rebased, or squash-merged. Superseded, never deleted — otherwise the timeline empties itself the moment the PR lands.
PhantomThe agent reported a commit git doesn't have. A known Claude Code failure mode; surfaced rather than trusted.
UncommittedMost sessions end here. Omitting it would lie by omission at exactly the moment someone resumes cold.
